# Week 3 Day 4: 组合方差与风险度量 ($w^T \Sigma w$)

## 1. 核心认知与代码解释
今天我们将前面生成的协方差矩阵 $\Sigma$ 投入实战，核心就是运用**马科维茨风险度量公式**测算组合的波动方差：
$$\sigma^2_p = w^T \Sigma w$$

在代码里表现为二次型乘法。这个基于理论推导（解析法）计算出的波动，被验证和纯历史面板序列（实证法）算出的波动等效完备：

```python
# 1. 解析法（马科维茨公式），利用 Day3 推导的 Sigma
step1 = Sigma @ w 
var_p = w @ step1  # 即 w.T @ Sigma @ w
sigma_p = np.sqrt(var_p)

# 2. 实证法（将历史日收益 R 乘权重 w，得到组合序列后再求标差）
portfolio_ret_series = R @ w  
sigma_p_historical = portfolio_ret_series.std(ddof=1)

# 两者计算完全吻合
assert np.isclose(sigma_p, sigma_p_historical)
```

## 2. 数理深度推导：从多项式展开到“田字格”可视化

### 2.1 你的直觉是对的：组合方差本质是个“巨大的平方式”
当我们看到 $N$ 种资产的组合方差时，如果你回想中学里的二项式展开公式：
$$(w_1 R_1 + w_2 R_2)^2 = w_1^2 R_1^2 + w_2^2 R_2^2 + 2 w_1 w_2 R_1 R_2$$

把它拓展到 $N$ 个资产的收益率 $R_p = \sum_{i=1}^N w_i R_i$ 时，由于 $Var(X) = Cov(X, X)$ 且方差拥有线性叠加的属性，整个投资组合的方差公式展开后，就是一个**包含了所有自身方差和两两相互协方差的巨大多项式**：

$$Var(R_p) = Var\left(\sum_{i=1}^N w_i R_i\right) = \sum_{i=1}^N \sum_{j=1}^N w_i w_j Cov(R_i, R_j)$$

### 2.2 可视化映射：多项式展开的“田字格”
为了更直观地理解，我们可以把这个巨大的多项式画成一个 $N \times N$ 的网格。以 3 种资产为例：

| | 乘 $w_1$ (资产1) | 乘 $w_2$ (资产2) | 乘 $w_3$ (资产3) |
|---|---|---|---|
| **乘 $w_1$** | $w_1 w_1 \sigma_{1,1}$ | $w_1 w_2 \sigma_{1,2}$ | $w_1 w_3 \sigma_{1,3}$ |
| **乘 $w_2$** | $w_2 w_1 \sigma_{2,1}$ | $w_2 w_2 \sigma_{2,2}$ | $w_2 w_3 \sigma_{2,3}$ |
| **乘 $w_3$** | $w_3 w_1 \sigma_{3,1}$ | $w_3 w_2 \sigma_{3,2}$ | $w_3 w_3 \sigma_{3,3}$ |

*   **对角线（$i=j$）**：就是各资产本身的风险贡献（例如 $w_1^2 \sigma_{1,1}$ 就是 $w_1^2 Var(R_1)$）。
*   **非对角线（$i \neq j$）**：这就是资产之间联动产生的相互影响项（相当于 $2ab$）。

**重点来了：这个网格里，如果我们把所有的 $w$ 剥离出去，中间剩下的核心数据矩阵 $\sigma_{i,j}$，正是我们造出来的“协方差矩阵” $\Sigma$！**

### 2.3 从田字格累加到矩阵代数 ($w^T \Sigma w$)
怎么优雅地把上面这个网格里所有的格子全部加起来？如果是线性代数，它就叫作**二次型（Quadratic Form）**：
*   **内层动作 `Σ @ w`**： 把协方差矩阵 and 列向量 $w$ 相乘。这步其实是按行把 $\Sigma$ 和 $w$ 一一对应乘起来，相当于把多项式里含有 $w_j$ 的项先行累加。
*   **外层动作 `w.T @ (Σ @ w)`**：再在左边补上一个行向量 $w^T$ 点乘。这就相当于把刚才的结果再分别乘以 $w_i$ 然后加总。

## 3. 性能突破：降维批量运算的数学机制

为了刻画组合的风险-收益云图并试图寻找最优解，代码通过 `np.random.dirichlet` 暴力生成了 50,000 组满足 $w_i>0, \sum w_i=1$ 的权重。
在计算这 5 万个组合的方差时，代码展示了 NumPy 的矩阵化批处理技巧：

```python
W_all = np.random.dirichlet(np.ones(N), size=50000) # shape: (50000, N)

# 🐌 传统 For 循环（慢）：
for i in range(50000):
    vars_loop[i] = W_all[i] @ Sigma @ W_all[i]

# 🚀 降维批量运算（极速，利用 BLAS 并行计算加速几十倍）：
WS = W_all @ Sigma                       # shape: (50000, N)
vars_matrix = (WS * W_all).sum(axis=1)   # 将矩阵再乘一次权重而后逐行求和 -> (50000,)
```

### 3.1 批量运算背后的降维打击过程
1.  **准备批量组合矩阵权重 $W_{all}$**：
    假设我们有 $M$ 个组合（例如 $M = 50,000$），且有 $N$ 个资产。将这些权重排布在一起，构成矩阵 $W_{all}$，形状为 **`(M, N)`**。这矩阵’的每一行就代表一个组合的特定权重配置。
2.  **第一步运算：批量投影 $WS = W_{all} @ \Sigma$**：
    *   **计算与维度变化**：`(M, N) @ (N, N)  →  (M, N)`
    *   **数学意义**：对每一行的权重向量 $w_i$，右乘协方差矩阵。此步骤等价于并行完成了 5 万次“计算单一组合内每个资产对应的风险敞口项 $\Sigma w_i$”。结果 $WS$ 矩阵的大小仍是 `(M, N)`。
3.  **第二步运算：哈达玛乘积与横向降维求和 `(WS * W_all).sum(axis=1)`**：
    *   **为什么不能直接 `W_all @ WS.T`？** 虽然结果矩阵的对角线上确实是所需的 5 万个方差标量，但它会顺带计算一个 `(M, M)`（也就是 50000 x 50000）的巨型协方差矩阵，会产生海量无逻辑交叉冗余计算，且会瞬间挤爆内存导致 OOM。
    *   **优雅解法**：我们用 Python 操作符 `*`，对 `WS` 矩阵和原生 `W_all` 矩阵执行**逐元素相乘（Hadamard Product）**。运算后矩阵仍旧为 **`(M, N)`**。
    *   最后，加上 `.sum(axis=1)`，将每一行（横向）加总，**精准降维收敛为 `(M,)` 的一维数组**。它将数十万次底层循环，转变成了两个基础底层的数组级 C 运算指令，充分释放了矩阵效率优势。

## 4. 三种典型业务组合的对比
通过 Monte Carlo 云图扫描，代码中找出了三个锚点级别的经典模型，直接通过 Numpy API 即可定位：
*   **等权组合**：`w_equal = np.ones(N) / N`
*   **MVP (最小方差组合)**：`w_mvp = W_all[np.argmin(port_var)]`
*   **最高夏普组合**：`w_max_sharpe = W_all[np.argmax(port_sharpe)]`
