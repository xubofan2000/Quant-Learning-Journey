## 1. 一张图串起 Week 3

```text
单日收益 r (N,) ── w @ r ───────────────→ 组合单日收益 float
历史收益 R (T,N) ── 去均值、转置、矩阵乘 ─→ 协方差 Σ (N,N)
权重 w (N,) + Σ ── w @ Σ @ w ─────────→ 组合方差 float
Σ (N,N) ── eigh ───────────────────────→ 特征值 λ (N,) + 特征向量 Q (N,N)
R (T,N) + 多组权重 W (M,N) ── R @ W.T → 批量收益 (T,M)
批量收益 (T,M) ── cumprod(axis=0) ─────→ 净值曲线 (T,M)
```

## 2. Shape 速查表

| 符号 | 含义 | Shape | 最容易犯的错 |
| --- | --- | --- | --- |
| `r` | 某一天 N 只资产收益 | `(N,)` | 与时间序列混淆 |
| `w` | 单个组合权重 | `(N,)` | 误以为 `w.T` 会变成列向量 |
| `R` | T 天、N 只资产收益 | `(T, N)` | 把资产放在行上后仍照搬公式 |
| `W` | M 个组合权重 | `(M, N)` | 忘记矩阵乘法前要写 `W.T` |
| `Σ` | 资产协方差矩阵 | `(N, N)` | 用 `T` 当分母做无偏估计 |
| `R @ W.T` | 所有日期、所有组合收益 | `(T, M)` | 写成逐元素乘法 `R * W` |
| `Q` | 特征向量矩阵 | `(N, N)` | 把行当作特征向量；`eigh` 返回的是列 |

## 3. 数学公式与 NumPy 映射

| 问题 | 数学 | NumPy |
| --- | --- | --- |
| 单日组合收益 | $r_p=w^Tr$ | `float(w @ r)` |
| 协方差矩阵 | $\Sigma=\frac{(R-\mu)^T(R-\mu)}{T-1}$ | `centered.T @ centered / (T - 1)` |
| 组合方差 | $\sigma_p^2=w^T\Sigma w$ | `float(w @ Sigma @ w)` |
| 组合波动率 | $\sigma_p=\sqrt{\sigma_p^2}$ | `np.sqrt(variance)` |
| 年化波动率 | $\sigma_{ann}=\sigma_d\sqrt{252}$ | `daily_vol * np.sqrt(252)` |
| 批量组合收益 | $P=RW^T$ | `R @ W.T` |
| 简单收益净值 | $NAV_t=\prod_{k=1}^t(1+r_k)$ | `np.cumprod(1 + returns, axis=0)` |

## 4. 五个必须重新长回来的直觉

1. **先看 Shape，再写公式。** `(T,N) @ (N,M)` 的内维 `N` 消失，保留 `(T,M)`。
2. **`*` 保留明细，`@` 沿共同维度汇总。** 组合收益需要把资产维度汇总，因此使用 `@`。
3. **NumPy 一维数组的 `.T` 不改变形状。** `w.shape == w.T.shape == (N,)`；公式里的 $w^T$ 是数学语义。
4. **风险来自协方差，不只是单个资产波动。** `w @ Σ @ w` 同时包含每只资产方差和资产之间的共同波动。
5. **向量化不是炫技。** `R @ W.T` 把 T 天 × M 个组合的循环交给底层线性代数实现，结果更清楚也更快。

## 5. PCA 验证的正确姿势

对称协方差矩阵应使用 `np.linalg.eigh` 或 `scipy.linalg.eigh`：

- 特征值按降序排列后，第一项表示最大方差方向。
- 特征向量是 `Q` 的列，不是行。
- 验证 `Q.T @ Q ≈ I`（正交性）。
- 验证 `Q @ diag(λ) @ Q.T ≈ Σ`（重构）。
- **不要断言 PC1 所有元素必须为正。** 若 `q` 是特征向量，`-q` 同样正确；整体符号没有唯一答案。

## 6. PortfolioMath 的工程边界

```text
数据层：读取 Parquet、处理日期、选择股票、清洗缺失值
                         ↓ 只交付 R / w / W / Σ
数学层：PortfolioMath 静态方法，只做可验证的纯计算
                         ↓
应用层：回测、绘图、报告、未来接入 VectorBT
```

`PortfolioMath` 不应自己读取 Parquet，也不应保存持仓状态。它的方法只依赖传入参数，因此适合使用 `@staticmethod`，并且容易测试和复用。
