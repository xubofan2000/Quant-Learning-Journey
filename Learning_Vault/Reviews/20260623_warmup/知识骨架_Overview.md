## 🗺️ 核心知识版图

### 1. 数据基建与时序特征工程 (Week 1-2)

#### 🔄 SQL 与 Pandas 思维映射
- **SELECT / WHERE** $\rightarrow$ `df.loc[condition, columns]`
- **GROUP BY** $\rightarrow$ `df.groupby('key').agg(...)`
- **JOIN** $\rightarrow$ `pd.merge(df1, df2, on='key', how='left')` （量化时序关联中极度危险：**必须防止右表有重复 Key 导致行数膨胀**）

#### 🩺 金融时序数据清洗
- **停牌与缺失值填充**：使用 `ffill`（用前一日的价格填充今日，符合金融实盘逻辑）后配合 `bfill`（处理首日缺失）。
- **移动均线 (SMA)**：`df['close'].rolling(window=20).mean()`
- **对数收益率 (Log Return) vs 简单收益率 (Simple Return)**：
  - **简单收益率**：$R_t = \frac{P_t - P_{t-1}}{P_{t-1}}$
  - **对数收益率**：$r_t = \ln(\frac{P_t}{P_{t-1}}) = \ln(P_t) - \ln(P_{t-1})$
  
| 维度 | 简单收益率 (Simple Return) | 对数收益率 (Log Return) |
| :--- | :--- | :--- |
| **时间可加性** | ❌ 无法直接相加。$1+R_{0,2} = (1+R_1)(1+R_2)$ |  两日对数收益率直接累加：$r_{0,2} = r_1 + r_2$ |
| **横截面可加性**|  **资产组合收益是各股票简单收益率的加权和**。 | ❌ 组合的对数收益率不等于各分量对数收益率的加权和。 |
| **数学性质** | 直观，适合对客户汇报和多资产组合收益计算。 | 适合学术研究、连续时间金融模型（如布朗运动）与统计建模。 |

### 2. 资产组合数学与 NumPy 矩阵运算 (Week 3)

#### 🥊 乘法对决：`*` (Element-wise) vs `@` (Matrix Multiplication)
- **`*` (逐元素乘法)**：依靠 **Broadcasting (广播机制)** 对齐维度，保留原始特征结构，是特征工程、批量相乘（如每日收益率乘权重）的利器。
- **`@` (矩阵乘法)**：依靠 **Contraction (维度坍缩)** 进行汇总计算，通常伴随内积求和，是计算组合收益、协方差、方差的核心。

#### 📐 资产组合维度变化 Cheat Sheet
假设有 $T$ 天历史，共有 $N$ 只股票，我们测试了 $M$ 个权重组合（策略）。

| 变量 | 概念含义 | 形状 (Shape) | 对应代码/数学运算 |
| :--- | :--- | :--- | :--- |
| $R$ | 历史日度收益率矩阵 | $(T, N)$ | `R = df.values` |
| $w$ | 单个组合权重向量 | $(N,)$ 或 $(1, N)$ | `w = np.array([...])` |
| $W$ | 批量策略权重矩阵 | $(M, N)$ | `W = np.random.dirichlet(...)` |
| $\mu$ | 各资产日均收益率向量 | $(N,)$ | `mu = R.mean(axis=0)` |
| $\Sigma$ | 协方差矩阵 (Covariance) | $(N, N)$ | `Sigma = (R - mu).T @ (R - mu) / (T - 1)` |
| $R_p$ | 单个组合的每日收益率 | $(T,)$ | `r_p = R @ w` |
| $R_{all}$ | 批量策略的每日收益率 | $(T, M)$ | `R_all = R @ W.T` |
| $\sigma_p^2$| 单个组合的方差 (二次型) | 标量 `()` | `var_p = w.T @ Sigma @ w` |
| $\sigma_{all}^2$| 批量策略的组合方差 | $(M,)$ | `vars = (W @ Sigma * W).sum(axis=1)` |

#### 🧬 协方差矩阵的金融直觉与推导
- **数学定义**：$\Sigma = \frac{1}{T-1} X_c^T X_c$，其中去中心化矩阵 $X_c = R - \mu$。
- **对角线元素**：即单个资产的样本方差 $\sigma_i^2$。
- **非对角线元素**：资产间的协方差 $\sigma_{ij}$。
- **矩阵性质**：
  - **对称性**：$\Sigma = \Sigma^T$。
  - **半正定/正定性**：对于任意非零权重 $w$，组合方差 $w^T \Sigma w \ge 0$。非对角线元素越小（相关性越低），分散化效应越强。

#### 💎 特征分解与 PCA (主成分分析)
- **数学方程**：$\Sigma v = \lambda v \implies \Sigma = Q \Lambda Q^T$
- **金融投影**：
  - 最大特征值 $\lambda_1$ 对应的特征向量 $v_1$（PC1）通常对应**市场 Beta 因子**（即全市场同涨同跌的系统性风险）。
  - 特征值的大小代表了该主成分解释了资产组合中多少比例 of 波动率（方差解释率 = $\lambda_i / \sum \lambda$）。
