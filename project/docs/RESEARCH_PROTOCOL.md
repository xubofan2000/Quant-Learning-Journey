# 量化研究协议

## 开始前的研究卡

每个策略、因子或模型必须先写一张研究卡，使用 `project/templates/RESEARCH_NOTE_TEMPLATE.md`。没有假设、数据口径和验证方案的代码只能放在练习目录，不能作为研究结论。

## 数据契约

每个数据集都要在研究卡中声明：

1. 标的池及其形成日期；是否包含退市标的。
2. 时间戳、时区、可得时点和调仓时点；信号只能使用该时点已知数据。
3. 价格口径、复权方法、停牌和缺失值规则。
4. 数据来源、提取日期、查询参数和不可公开的数据限制。
5. 行数、日期范围、唯一键与质量检查结果。

## 标准研究流程

1. 写出可被证伪的假设、经济直觉和零假设。
2. 在开发集完成特征定义；锁定规则后才能查看验证集。
3. 按时间划分训练、验证、样本外区间；不得随机打散时间序列。
4. 将信号、持仓、调仓、成本和净值拆成独立步骤并分别检查。
5. 报告基准、收益、波动率、最大回撤、换手、成本前后差异和样本外结果。
6. 执行稳健性测试：不同窗口、滞后、成本、子样本和股票池。
7. 记录失败假设与负结果，禁止只保留收益最好的尝试。

## 回测最低门槛

- 信号日期必须早于交易日期；所有合并均检查未来数据泄漏。
- 明确手续费、滑点、印花税/市场规则与无法成交的假设；未知时宁可使用保守假设。
- 将调仓频率、成交价格、停牌处理、现金与权重约束写成配置，而不是藏在代码里。
- 因子挖掘需控制多重检验；同一数据上的大量尝试不能视为独立证据。
- 任何“可实盘”结论都必须先经过滚动样本外和模拟执行验证。

## 结论分级

| 级别 | 含义 |
| --- | --- |
| 练习 | 用于理解 API 或数学，没有可交易结论 |
| 探索 | 有假设与初步结果，但尚未锁定规则 |
| 验证 | 完成样本外、成本和稳健性检查 |
| 候选 | 可进入模拟执行，仍不等于可以真实下单 |
