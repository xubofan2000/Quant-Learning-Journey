# 量化研究协议

## 开始前的研究卡

每个策略、因子或模型必须先写一张研究卡，使用 `project/templates/RESEARCH_NOTE_TEMPLATE.md`。没有假设、数据口径和验证方案的代码只能放在练习目录，不能作为研究结论。

## 数据契约

每个数据集都要在研究卡中声明：

1. 标的池及其形成日期；是否包含退市标的。
2. 时间戳、时区、可得时点和调仓时点；信号只能使用该时点已知数据。
3. 价格口径、复权方法、停牌和缺失值规则。
4. 数据来源、提取日期、查询参数和不可公开的数据限制。
5. 行数、日期范围、唯一键与质量检查结果。
6. 数据是真实、模拟还是混合；模拟数据只能支持接口/模型理解，不能支持市场有效性结论。
7. 财务/基本面数据的 Point-in-Time 可得性；若无法可靠获得，明确禁止价值、质量等有效性结论。

## 标准研究流程

1. 写出可被证伪的假设、经济直觉和零假设。
2. 在开发集完成特征定义；锁定规则后才能查看验证集。
3. 按时间划分训练、验证、样本外区间；不得随机打散时间序列。
4. 将原始数据、信号、目标持仓、实际持仓、调仓、成交、成本、现金、净值和基准拆成独立步骤并分别检查。
5. 报告基准、收益、波动率、最大回撤、换手、成本前后差异和样本外结果。
6. 执行稳健性测试：不同窗口、滞后、成本、子样本和股票池。
7. 记录失败假设与负结果，禁止只保留收益最好的尝试。

## 回测最低门槛

- 信号日期必须早于交易日期；所有合并均检查未来数据泄漏。
- 明确手续费、滑点、印花税/市场规则与无法成交的假设；未知时宁可使用保守假设。
- 将调仓频率、成交价格、停牌处理、现金与权重约束写成配置，而不是藏在代码里。
- 因子挖掘需控制多重检验；同一数据上的大量尝试不能视为独立证据。
- 任何“可实盘”结论都必须先经过滚动样本外和模拟执行验证。
- `R @ W.T` 只计算固定权重下的批量理论收益，不是完整回测。完整回测必须处理手续费、印花税、滑点、无法成交、现金和基准。
- 研究特征中不得用可能读取未来值的 `bfill`。缺失处理必须按可得时点和业务场景定义，并有泄漏测试。

## 统计与模型表述

- p-value 是在零假设、抽样机制和模型假设成立时，对当前或更极端统计量的概率刻画；它不证明策略赚钱不是运气，也不度量经济重要性。
- 同时报告效应大小、置信区间、样本外表现、成本和模型诊断。统计显著不等于经济可交易。
- Monte Carlo/GBM 用于情景模拟、风险分析和模型理解；结果依赖分布与参数假设，不称为可靠预测未来股价。
- PCA 的 PC1 是样本中的最大方差方向。只有结合真实数据、载荷结构、市场代理、跨期稳定性等证据，才可谨慎讨论其市场因子解释；模拟数据不能“证明”它是 Beta。
- 随机权重组合的矩阵计算是向量化演示，不是策略有效性、最优组合或完整交易系统的证据。
- 最高收益、最高夏普和样本内最优结果只能生成待验证假设，不能作为有效性的充分证据。
- AI 生成的研究代码必须由学习者独立复现关键逻辑、通过测试并口述数据时点、假设和失效条件。

## 结论分级

| 级别 | 含义 |
| --- | --- |
| 练习 | 用于理解 API 或数学，没有可交易结论 |
| 探索 | 有假设与初步结果，但尚未锁定规则 |
| 验证 | 完成样本外、成本和稳健性检查 |
| 候选 | 可进入模拟执行，仍不等于可以真实下单 |

只有“验证”及以上可以使用最终样本外结论；“候选”仍需模拟执行和独立风险审查。学历、岗位门槛或真实交易授权不属于研究结论可以覆盖的范围。
