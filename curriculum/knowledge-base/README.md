## 必须使用的知识勘误

- p-value 不证明策略有效或赚钱不是运气。
- Monte Carlo/GBM 用于情景模拟、风险分析和模型理解，不可靠预测未来股价。
- PCA 的 PC1 是最大方差方向；模拟数据不能证明其为市场 Beta。
- `R @ W.T` 是固定权重批量收益演示，不是完整回测。
- GitHub 星数、高收益、最高夏普或样本内最优都不是就业能力或策略有效性的充分证据。
- AI 生成代码必须由学习者独立复现、测试和口述解释。
