# [02_Phase2_框架与因子]

**当前定位**：建立真实金融数据契约、因子研究、正式回测和样本外验证。框架是可替换实现，不是课程目标；RAG/FinGPT 已从主线移除。

**核心能力**：

1. 数据来源、提取日期、可得时点、股票池、复权、停牌、退市、ST、缺失和交易日历。
2. 动量、低波动、流动性、反转/趋势等数据口径可靠的因子。
3. IC、Rank IC、ICIR、分层、多空、换手、相关性、去极值、标准化和中性化。
4. 信号、目标/实际持仓、成交、成本、现金、净值和基准分层。
5. 开发/验证/最终 OOS、稳健性、多重检验和失败实验。

**核心资源清单**：
1. **VectorBT 官方文档**（可选实现参考，使用前核验当前维护状态）
   - 链接: https://vectorbt.dev/
2. **Alphalens**（历史因子评价参考，不作为唯一实现）
   - 链接: https://github.com/quantopian/alphalens
3. **Pandas / NumPy / SciPy 官方文档**（优先理解指标和时序逻辑，再选框架）

**基本面边界**：只有可靠 PIT 财务数据才允许研究价值、质量等因子；模拟财务数据只可测试接口。
