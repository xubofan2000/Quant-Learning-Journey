# [03_Phase3_Agent架构]

**当前定位**：延后选修，最多 2-3 周。只有至少一个真实因子项目完成最终样本外验证、主项目无 LLM 可复现且已经开始求职后才可进入。

**范围**：单 Agent、白名单确定性工具、最小评估集、引用与人工否决。多智能体、通用 MCP 平台和复杂 LangGraph 架构不属于一年主线。
