# [01_Phase1_基建与数理]

**当前定位**：服务量化数据开发、研究平台 Python 和投研/风险数据支持的基础阶段。重点是 Python、SQL、Pandas/NumPy/DuckDB、线性代数、概率统计、Linux/Git/测试，而不是追求工具数量。

**退出门槛**：学习者能不看答案实现收益率、协方差和组合风险，通过正常/边界/非法输入测试，并解释统计假设与金融含义。历史教学文件和打卡不能单独满足门槛。

**核心资源清单**：
1. **DuckDB Python 官方文档** (本地基建)
   - 链接: https://duckdb.org/docs/api/python/overview
2. **Python for Data Analysis** (Pandas 数据处理映射)
   - 链接: https://wesmckinney.com/book/
3. **Mathematics for Machine Learning** (基础数理补习)
   - 链接: https://mml-book.github.io/

**表述边界**：p-value 不证明策略有效；Monte Carlo/GBM 不可靠预测未来股价；PCA 的 PC1 不自动等同市场 Beta。详见 `project/docs/RESEARCH_PROTOCOL.md`。
