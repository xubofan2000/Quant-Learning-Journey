# Phase 3 执行计划：Agent / LLM 延后选修（最多 2-3 周）

> 原第 6-7 月、8 周 Agent 主线已被压缩并延后。Agent、MCP、LangGraph 和多智能体架构不是一年内第一求职目标的核心门槛。

## 前置门槛

只有同时满足以下条件才允许开始：

1. 至少一个真实数据因子项目完成锁定规则、成本建模和最终样本外验证。
2. 主项目可在无 LLM 条件下复现，量化核心测试和 CI 通过。
3. 已完成一页简历、项目讲解和第一轮真实投递；Agent 不得推迟求职。
4. 当周仍能保持 Python/SQL/Linux 面试训练。

任一条件不满足时，本阶段标记为“延后/可选”，时间转投数据工程、研究方法或求职反馈补强。

## 2-3 周上限

| 周 | 范围 | 交付物 | 退出门槛 |
| --- | --- | --- | --- |
| 1 | 确定性研究工具接口与 LLM 边界 | 白名单工具、输入输出 schema、无 LLM 基线 | 给定同一数据和配置可重复 |
| 2 | 单 Agent 辅助资料整理/实验编排 | 最小评估集、引用和人工否决路径 | 相比基线的时间/质量改进可量化 |
| 3（可选） | 失败、拒答与审计 | 20 个正常/模糊/错误前提样本 | 报告错误率、人工纠正率和不可接受案例 |

## 禁止扩张

- 不建设多 Agent 平台、复杂 MCP 生态或通用 LangGraph 架构。
- Agent 不直接交易、不修改历史结果、不删除数据、不拥有密钥。
- 流畅回答不代表研究正确；AI 代码仍需学习者独立复现、测试和口述。
- 2-3 周结束后回到作品集、面试、投递或主研究线，不继续堆叠框架。
