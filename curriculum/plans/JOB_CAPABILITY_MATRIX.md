## 2. 能力等级与掌握规则

能力等级必须按证据逐级推进，不允许因为文件存在、AI 已生成代码或历史打卡而跳级。

| 等级 | 状态 | 最低证据 |
| --- | --- | --- |
| L0 | 未学习 | 尚无有效输入或实践 |
| L1 | 已接触 | 阅读或跟随示例，能指出主题用途 |
| L2 | 能看懂 | 能逐段解释已有实现，能指出主要输入、输出和风险 |
| L3 | 能不看答案独立实现 | 在隔离环境从空白或骨架完成，保留提交或屏幕录制/现场记录 |
| L4 | 能通过测试 | 正常、边界和非法输入测试通过；失败时进程返回非零 |
| L5 | 能解释金融含义和假设 | 能口述数据可得时点、统计假设、经济直觉、失效条件和限制 |
| L6 | 能用于完整项目 | 能在可复现项目中连接数据、研究、测试、报告或求职反馈 |

“掌握”是门槛而不是自评：同一能力至少同时满足 **L3 独立实现、L4 测试通过、L5 能解释**。L6 代表已用于完整项目。任何一项证据失效时应降级或标记待复验。

## 5. 更新规则

1. 每周复制 `project/templates/WEEKLY_ACCEPTANCE_TEMPLATE.md` 形成验收记录。
2. 只有学习者本人完成独立实现后，才能把能力提升到 L3。
3. 自动测试命令、退出码和测试数量必须写入证据；仅截图“成功”不够。
4. L5 必须记录口述问题与学习者自己的回答摘要，AI 代写答案无效。
5. L6 必须链接到可复现项目、报告、面试反馈或真实求职数据。
6. 每两周重审一次矩阵；没有新证据时保持原等级，不按日历自动升级。
